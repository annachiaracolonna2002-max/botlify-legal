Informativa sulla Privacy

Ultimo aggiornamento: Ottobre 2026

La presente Informativa sulla Privacy descrive come Bot di Botlify Music raccoglie, utilizza e protegge i dati degli utenti quando utilizzano il nostro bot su Discord.

1. Quali dati raccogliamo

Per il corretto funzionamento dei comandi e delle preferenze, il Bot può raccogliere i seguenti dati strettamente necessari:

  • ID Utente e ID Canale: Utilizzati per gestire code musicali, preferenze e comandi impartiti.
  • ID del Server (Guild ID): Necessario per memorizzare configurazioni specifiche del bot per ogni singolo server.
  • Log tecnici: Eventuali messaggi di errore o dati tecnici temporanei utili al debug e alla stabilità del servizio.

2. Come utilizziamo i dati

I dati raccolti vengono impiegati esclusivamente per:

  • Eseguire i comandi musicali richiesti (es. riproduzione tracce, gestione playlist).
  • Migliorare le prestazioni e la stabilità del servizio.

Non vendiamo, scambiamo o cediamo in alcun modo i dati degli utenti a terzi.

3. Conservazione dei dati

I dati tecnici e le configurazioni dei server vengono conservati solo per il tempo strettamente necessario all'erogazione del servizio. Puoi richiedere la cancellazione dei dati associati al tuo server rimuovendo il Bot o contattando il supporto.

4. Sicurezza

Adottiamo misure di sicurezza ragionevoli per proteggere le informazioni da accessi non autorizzati, alterazioni o diffusioni.

5. Contatti

Per qualsiasi domanda o richiesta riguardante la privacy, puoi contattare il team di sviluppo tramite il server di supporto ufficiale di Discord.
